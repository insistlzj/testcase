# 三端流程索引

下表是本轮新用例的联调顺序和分支索引。每条仍按自己的前置条件执行；不把所有同流程编号的正常、驳回、失败用例串成同一次运行。

## 入会认证

同一申请 ID；先公会初审，再平台终审。通过前与通过后使用对应的观察用例。

| 端 | 用例编号 | 检查内容 |
| --- | --- | --- |
| 用户App | USER-0060 | 验证提交完整材料后产生初审申请 |
| 公会App | GUILD-0030 | 验证公会同意后进入平台终审 |
| 用户App | USER-0070 | 验证平台通过前尚未建立成员关系 |
| 管理后台 | ADMIN-0276 | 验证平台终审通过才授予主播身份 |
| 用户App | USER-0071 | 验证平台通过后显示已加入 |
| 公会App | GUILD-0033 | 验证平台终审通过后显示最终进度 |

## 退会

同一成员关系及退会申请 ID；同意、驳回使用不同申请样本。

| 端 | 用例编号 | 检查内容 |
| --- | --- | --- |
| 用户App | USER-0078 | 验证填写退会原因产生审核申请 |
| 公会App | GUILD-0038 | 验证退会审核同意解除成员关系 |
| 用户App | USER-0075 | 验证退会通过后显示已退出 |
| 用户App | USER-0050 | 验证退会通过后不再具有主播身份 |
| 公会App | GUILD-0039 | 验证退会审核驳回保留主播 |

## 充值与退款

同一充值订单关联用户余额；每条金额核算用例独立准备其指定余额，不能直接接用上一条的余额。

| 端 | 用例编号 | 检查内容 |
| --- | --- | --- |
| 用户App | USER-0084 | 验证充值基础与赠金合并到账 |
| 管理后台 | ADMIN-0001 | 验证整单退款扣回本金和赠金 |
| 管理后台 | ADMIN-0005 | 验证退款不撤销完成的礼物消费 |
| 用户App | USER-0420 | 验证主播收益不受充值退款回退 |

## 线下分成

同一主播、公会及财务导入批次；主播分成与公会分成分别核对。

| 端 | 用例编号 | 检查内容 |
| --- | --- | --- |
| 管理后台 | ADMIN-0011 | 验证主播确认导入后记录只读 |
| 用户App | USER-0406 | 验证主播读取财务上传结果 |
| 公会App | GUILD-0043 | 验证公会读取本会主播上传结果 |
| 管理后台 | ADMIN-0018 | 验证公会确认导入后记录只读 |
| 公会App | GUILD-0044 | 验证公会分成只展示当前公会 |

## 公会停用

同一个启用公会；停用公会与仅停用公会长账号是两种不同场景。

| 端 | 用例编号 | 检查内容 |
| --- | --- | --- |
| 管理后台 | ADMIN-0031 | 验证停用公会解绑旗下主播 |
| 用户App | USER-0068 | 验证停用公会不参与搜索 |
| 管理后台 | ADMIN-0032 | 验证只停用公会长账号不解绑主播 |
| 公会App | GUILD-0024 | 验证停用公会长不能登录 |

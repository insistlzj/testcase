## 3. 按端展开

### 用户/主播 App

- 系统入口：登录与注册、资料补全、手机号登录。

- 直播：观众直播间、举报直播间、举报用户、主播直播间、主播密码房、主播连麦、观众结束页、主播结束页。
- 消息与社交：消息、系统通知、私信、粉丝团群聊、成员/群主群管理、单聊设置、好友列表、互动通知、用户主页、主播主页、主播礼物展馆。
- 我的：我的、资料编辑、我的关注、我的装扮、头像框、聊天气泡、勋章、设置、黑名单、我的粉丝团、粉丝团贡献榜。
- 公会关系：公会中心、申请加入公会、我的公会、公会详情、申请退出公会。
- 主播中心：主播中心、房管管理、公会通知、申请成为主播、开播设置、粉丝列表、粉丝团、粉丝团设置、直播数据、直播记录、分成记录、我的银行卡、添加银行卡、提现填写。
- 钱包与账单：余额充值、余额明细、充值订单详情、支出订单详情。

### 公会 App

- 登录与首页：公会登录、选择公会、首页、通知消息、通知详情。
- 主播管理：入会申请及详情、退会申请及详情、主播列表、主播业绩、主播数据、主播主页。

- 公会管理：公会资料、账号设置、修改密码。
- 数据与收益：公会业绩、每日、直播记录、直播场次详情、违规记录、主播分成记录、公会分成记录、全部直播记录、选择主播（多选）。

### 管理后台 Web

- 工作台：工作台。
- 用户管理：用户列表、用户详情、封禁申诉、申诉详情。
- 主播管理：主播审核及详情、主播列表及详情、直播场次及详情、巡房排班/新建/详情、内容审核及详情。

- 公会管理：公会列表、公会详情。
- 礼物道具：普通礼物及详情、定制礼物、幸运礼物及详情、道具配置及详情、购买份数配置及详情。

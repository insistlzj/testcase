# 移动端 App 原型 · 配色规范


---
## 容器规范
- 页面逻辑宽度：390px
- 页面逻辑高度：844px
- 查看器 iframe：390 × 844
- 页面根容器：.screen { width: 390px; min-height: 844px; }
- 查看器按预览区等比缩放，不改变页面内部逻辑尺寸
- 内容超出 844px 时，按页面内容自然向下延展，由页面 / iframe 垂直滚动查看
- 页面内部不建议横向滚动；特殊表格可在局部容器内横向滚动
### 基础栏高度
- 状态栏：44px class：.sb
- 左侧时间、右侧信号/电量 padding：左右 20px

- 标题栏：44pxclass：.nav
- 返回按钮区域宽：30px
- 标题居中，字号 17px，加粗 padding：左右 16px

###底部操作栏：
- 内容型高度class：.bbar
position: sticky; bottom: 0
padding：上下 10px，左右 16px
- 常规按钮高约 44px，按钮 padding 11px 26px
实际总高约 65px

### 菜单栏 / Tab 规范
- 顶部 Tab：内容型高度，常规约 40pxclass：.tabs 或 .ttab
单项 padding：上下 10px 或 11px
- 字号：14px–15px
- 选中态下划线：宽 24–26px，高 3px


### 页面分组标题：class：.sec
- 字号 15px
- 上边距常用 14–18px
- 左右 16px

### 可视区计算
- 常规带状态栏 + 标题栏页面：
- 顶部固定占用：44 + 44 = 88px
- 首屏内容可用高度约：844 - 88 = 756px
- 如有底部操作栏，再预留约 65px，主体首屏可用高度约 691px

## 一、7 阶灰度令牌（深 → 浅）

| 令牌 | 色值 | 名称 | 用途 |
|---|---|---|---|
| --g1 | #333333 | 深黑 | 页面标题、卡片标题、重点文字、主按钮底色、选中态、深色角标底、进度条填充、在播态标识、图标重色 |
| --g2 | #555555 | 深灰 | 次级重点文字、线性图标描边、线框标签文字与描边 |
| --g3 | #7F7F7F | 中灰 | 说明性文字、封面占位标注文字、奖励表达式（+ icon 数值） |
| --g4 | #AAAAAA | 浅中灰 | 辅助文字、时间戳、输入框占位、未选中 Tab 文字 |
| --g5 | #D7D7D7 | 浅灰 | 封面/图片占位底、头像占位底、Home 指示条、箭头符号、结构性分隔线（Tab Bar 顶线） |
| --g6 | #F2F2F2 | 页面底灰 | 页面背景色；白色块内部的次级底（签到格、图标底托、按下态回填） |
| --g7 | #FFFFFF | 白 | 内容块底色、主按钮文字、深底上的反白元素、头像描边 |

页面内仅允许以上 7 色。禁止：彩色、渐变、阴影、发光、透明度叠加。

## 二、底色嵌套规则（层级的唯一表达方式）

```
页面底 --g6（#F2F2F2）
 └ 内容块 --g7（白，无边框，圆角 12，靠明度差与底色分界）
     └ 块内次级元素 --g6 回填（签到格 / 图标底托 / 按下态）
         └ 占位图 --g5（封面、头像等需要"图片感"的位置，比次级底再深一档）
```

- 白色内容块**不加边框**——#F2F2F2 与 #FFFFFF 的明度差即分界；边框仅保留在必须独立成钮的小元件上（榜单胶囊等）。
- 白块内的行分隔线用 --g6；跨结构分隔（Tab Bar 顶线、画板边框）用 --g5。

## 三、文字层级映射

| 层级 | 字号（v0.5 不变） | 颜色 |
|---|---|---|
| 页面大标题 / 卡片标题 / 数字重点 | 28 / 16–17 / 20–24 | --g1 |
| 次级标题、图标语义文字 | 15–16 | --g2 |
| 说明文字 | 13 | --g3 |
| 辅助/时间/占位 | 11–13 | --g4 |
| 弱化信息（如 ID） | 11 | --g5 |

## 四、组件配色映射

| 组件 | 配色规则 |
|---|---|
| 主按钮 | 底 --g1，文字 --g7；**按下态：轻微缩放 scale(0.97)**（最深阶无更深色，不做变色） |
| 次按钮 | 白底 --g7 + 1px --g5 描边，文字 --g2；按下态底色回填 --g6 |
| 奖励表达式 | "+ [金币 icon] 数值"，icon 描边与数字均 --g3（在按钮上时随按钮文字色） |
| 标签 · 深色 | 底 --g1，文字 --g7（如"群"标） |
| 标签 · 线框 | 1px --g2 描边，文字 --g2（如"直播间私信"、等级徽标） |
| 标签 · 浅底 | 底 --g6，文字 --g2 |
| 选中态（Tab / 排序 / 分类） | 文字 --g1 加粗；下划线指示条 --g1；分类 chip 选中为 --g1 底 + --g7 字 |
| 未读角标 / 计数点 | 底 --g1，文字 --g7 |

| 进度条 | 轨道 --g6，填充 --g1 |
| 头像占位 | 底 --g5，首字母 --g3；白描边 --g7（压在图片/背景上时） |
| 已关注卡片 | 1.5px --g1 描边（唯一的卡片描边用法） |
| 图标 | 线性风格，描边 --g2，1.6px；重要态可用 --g1 |

## 五、动效与状态

- 允许的按下反馈：底色回填 --g6（浅底元件）或 scale(0.97)（深底主按钮），二选一，不叠加。
- 允许的循环动效仅一处语义：**在播态**（脉冲/闪动）；须尊重 prefers-reduced-motion（降级为静态标识）。
- 其余一切装饰性动效禁止。

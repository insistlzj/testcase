# Luma Live 项目说明

## 项目范围

面向印尼市场的直播产品原型，包含三端：

- 用户/主播 App
- 公会 App
- 管理后台 Web

用户与主播共用账号；通过工会入会和平台认证后获得主播身份及直播权限。

## 原型约定

- 原型是开发依据；页面与批注必须同步更新。
- 从 `prototype/index.html` 查看全部页面；每个页面只对应一个 HTML 文件。
- 页面位于 `prototype/pages/user/`、`prototype/pages/guild/`、`prototype/pages/admin/`。
- 静态原型不发真实网络请求。关键操作用页面交互或 Toast 表达结果。
- 修改页面时，同时检查 `prototype/assets/annotations.js`、`prototype/assets/mock.js` 与 `prototype/index.html` 的页面登记。

## 当前关键规则

- 用户 App、公会 App：英语、马来西亚语、印尼语；管理后台一期仅中文，但需预留国际化。
- 连麦与 PK 一期只支持两位主播；门票房、密码房均不支持连麦或 PK。
- 主播有效天：单个自然日累计直播时长不少于 3 小时计 1 天，每自然日最多计 1 天。
- 主播等级按累计收到的贡献值计算；等级阈值和权益尚未定义。
- 主播可通过用户 ID 设置房管，无需在线或好友关系；目标不得在该主播直播间黑名单内，且双方无账号拉黑关系；每位主播最多 3 名房管。
- 直播间可屏蔽单条评论：长按后确认，前台不可恢复，后台保留内容和操作记录。
- 头像、昵称提交后经后台风控检测；通过自动生效，不通过不生效。背景图及其他资料字段直接保存。
- 关注、好友、粉丝团是不同关系；具体以互动权限规则为准。
- 虚拟金币仅用于运营，不计入真实收益和分账。

## 资金与结算

现行项目规则：主播在线发起提现申请，管理后台审核，财务线下打款；公会不参与单笔主播提现审批，但可查看收益和分账台账。

近期讨论结论：无论平台直付或公会代付，均应先由平台完成业绩核算、退款红冲/冻结处理和主播/公会/平台分成确认，再进入付款链路。该结论尚未完整回写至现有规则文件，后续变更需先统一结算责任方与流程。

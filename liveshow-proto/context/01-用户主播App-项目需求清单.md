## 用户/主播端 App —— 用户/观众侧

### 账号与登录（用户与主播共用）

- **第三方登录**：
	- 支持 4 种第三方一键登录：Google、Facebook、Apple ID、TikTok。点击对应图标唤起授权，授权成功后进入 App；首次登录自动创建账号并初始化基础资料（默认昵称、默认头像、系统分配用户 ID）。
- **手机号登录**：
	- 手机号 + 短信验证码登录。输入手机号（带国家区号，默认 +62 印尼）后点击获取验证码，60 秒倒计时期间按钮置灰；验证码 6 位、有效期 5 分钟；连续错误 5 次锁定当前验证码需重新获取。短信通过第三方国际短信网关下发。
  - 手机号 + 密码登录：已注册用户可用手机号 + 密码直接登录；支持忘记密码经验证码重置。
- **邮箱注册登录**：
	- 邮箱验证码：邮箱 + 验证码注册/登录。
  - 邮箱密码：已注册邮箱 + 密码登录；支持忘记密码经邮箱验证重置。
- **账号安全与协议**：App 内账号注销：提交注销申请、二次确认、按平台规则冷静期后清除账号。注销前若有未提现收益/未消费金币，提示处理后注销。
  - 首次启动展示《用户协议》《隐私政策》，需勾选同意方可进入。

### 用户资料

- **个人资料**：
	- 资料字段：头像、昵称、性别、地区、生日、个性签名、用户 ID、财富等级标识。头像/昵称修改提交后由后台风控检测；检测通过自动修改成功，检测不通过不生效。

### 首页与发现

- **直播广场**：
	- 直播列表：卡片展示本场封面、主题、主播、分类、本场访问次数和房型标识；列表提供“热门”“新人”两个 Tab。已关注且正在直播的主播在 Tab 上方独立展示，无符合数据时隐藏该区域。
  - 分类：按平台当前配置的分类筛选直播间；热门列表可展示运营 Banner。
- **搜索**：支持搜索主播昵称、用户 ID、直播间。展示搜索历史、热门搜索词（后台可配）。无结果时展示空状态。

### 直播观看与互动

- **进入直播间**：
    - 普通房：符合账号和关系限制的用户可免费进入，直接展示直播内容。
  - 门票房（首版上架后经后台开关灰度开启）：直播内容在购票前被遮挡；支付成功后进入，同一场次重复进入不再收费。直播结束或被主播踢出后门票失效且不退款；不支持连麦或 PK。
  - 密码房（首版上架后经后台开关灰度开启）：是否在广场展示由主播设置；用户输入当前场次 4-12 位数字密码，校验通过后进入。账号封禁、拉黑和本场踢出优先拦截；不支持连麦或 PK。
- **直播间互动**：
		- 公屏聊天/弹幕：发送文字消息、系统进场提示、表情。敏感词库由后台维护；命中后的拦截、替换和提示方式待确认。
  - 点赞、关注主播。观众可调起系统分享；主播可转发到粉丝群或好友，接收人仍按房间准入规则进入。
  - 查看主播主页、查看在线观众列表、查看本场贡献榜。
  - 进场特效：一期不做，二期落地。

### 礼物与打赏

- **礼物赠送**：
	- 礼物面板：展示礼物分类、列表（图标+名称+金币价格）、当前金币余额、充值入口。选择礼物与数量后赠送，金币不足时引导充值。
  - 连击/连送：同一礼物连续赠送触发连击计数与叠加特效。
  - 礼物特效：普通礼物轻动效在公屏区播放；大额礼物触发全屏特效（特效素材由客户提供）。
  - 赠送结果：扣减用户金币、增加主播收益（前端按金币 1:1 展示，不在前端扣分成）、公屏播报"X 送出 Y"。
- **礼物类型（后台配置、分类展示）**：
	- 普通礼物：常规礼物，长期上架。
  - 幸运礼物（盲盒概率玩法，首版上架后经后台开关灰度开启）：用金币购买/赠送，按后台配置概率开奖，中奖返还金币（返金币而非返实物）；赠送成功公屏播报中奖信息；礼物面板/详情展示中奖概率与奖励档位。
  - 定制礼物：限时/节日/活动礼物，具有时效性，由平台运营定期维护上下架。
- **幸运礼物玩法说明**：
	- 玩法：一期采用固定概率。基础金币 10/次，6 档奖励：0 / 5 / 10 / 50 / 100 / 1000 金币，首期最高 100 倍。
  - 返奖率(RTP)按连送口径分三档（连送也按单个礼物逐个计算）：单次（消耗 10）=96%；连送 10 次（消耗 100）=97%；连送 100 次及以上（消耗 1000）=98%。
  - 各档中奖概率（奖励 0/5/10/50/100/1000 金币）：96% 档 = 10.4% / 32% / 55% / 2% / 0.5% / 0.1%；97% 档 = 8.4% / 34% / 55% / 2% / 0.5% / 0.1%；98% 档 = 6.4% / 36% / 55% / 2% / 0.5% / 0.1%。
  - RTP、各档概率、奖励倍数均后台手动可调；上线后先在测试环境跑大样本（数十万次）验证实际返奖，再按运营情况动态调整（后续可加保底/更高倍数档）。
- **榜单**：
	- 榜单类型 3 种：主播榜（收礼）、财富榜（送礼）、粉丝榜（对单主播贡献）。周期支持日/周/月切换，展示排名+头像+昵称+数值。
  - 【7.20改】数值展示：榜单、直播间等大数值按 K/M/B 缩写展示（1,000=1K，10,000=10K，100,000=100K，1,000,000=1M，1,000,000,000=1B），隐藏小数保证爽感；主播个人中心收益页展示全额、精确到个位（便于主播核对工资）。

### 签到与任务

- **每日签到**：
	- 每日签到领奖（金币/道具/经验），连续签到额外奖励；展示已签到天数、连续签到进度、断签重置规则；奖励发放到账（道具入背包、金币入钱包）。
  - 签到/任务可发放道具：头像框、勋章、发言气泡等。
- **任务中心**：
	- 日常/成长任务（如观看时长、关注、送礼、分享），任务进度展示、完成后手动/自动领取奖励，奖励到账。
  - 签到与任务的奖励规则、任务项均由后台配置。

### 邀请拉新（推广获客）

- **我的邀请码**：
	- 每个用户生成专属邀请码，支持分享到外部社交。
- **绑定关系**：
	- 新用户注册时填写邀请码与邀请人建立绑定关系；一名用户仅可被绑定一次，绑定后不可更改。
  - 管理后台可手动为用户建立/调整邀请绑定关系。
- **注册奖励**：
	- 被邀请人完成注册并绑定成功后，向邀请人发放赠送金币（是否同时给被邀请人、奖励额度由后台配置）。
- **充值返利**：
	- 被邀请人充值后，按规则向邀请人发放返利金币；返利规则（按累计充值金额/按充值比例/有效期）由后台配置。
- **我的拉新（数据统计）**：
	- 邀请人查看名下已绑定人数、每名成员带来的返利金币明细、累计获赠金币；支持查看绑定成员列表与状态。
- **防刷限制**：
	- 同设备/同支付账号/异常绑定的风控限制（后台可配），命中风控的奖励不发放或冻结。

### 用户成长与身份

- **财富等级**：
	- 按累计充值/消费成长的财富等级，展示在资料页与直播间昵称旁。一期仅展示等级数字；UI 上按等级做视觉区分（不同等级对应不同等级图标/徽标/颜色标识），等级数值与图标由后台配置。

### 粉丝团（用户侧）

- **加入粉丝团**：
	- 加入条件由主播设置（如关注/送礼门槛）；加入后获得粉丝灯牌、粉丝头衔/勋章，在该主播直播间聊天展示身份标识。
  - 粉丝团等级：粉丝团自身的等级；长时间不活跃自动降级，等级影响粉丝团等级勋章的样式。
  - 粉丝等级 / 亲密度：均为用户对该主播的关系成长值。粉丝等级是用户在该粉丝团内的社群身份（如 Lv.10）；亲密度是用户与该主播的一对一关系数值（如 1,023）。

### 钱包与充值

- **金币钱包**：
	- 展示当前金币余额（用户资产中心）。
- **充值**：
	- iOS 走 Apple IAP；Android 及网页 H5 走第三方/印尼本地钱包通道。展示多档金币套餐（后台可配档位与定价）、新人首充礼包（后台可配）。
  - 网页 H5 充值：App 外提供 H5 充值页（按印尼盾计价、订单支付倒计时、客服入口），规避应用商店抽成。
  - 第三方支付渠道拟接入：空中云汇（Airwallex）、PayerMax。
- **账单与明细**：
	- 充值记录：订单、金额、渠道、状态。
  - 消费记录：送礼/购票等金币消费流水。
  - 金币收支明细：进出汇总。

### IM 社交

- **私信：用户与用户/主播一对一私信（对接 IM SDK），支持发送文字、图片、语音。**：
	- 私信关系规则：主播私聊用户不做限制；用户私聊主播需先申请成为主播好友、主播通过后方可私聊。
- 群聊：粉丝团群。
- 关系：
	- 关注列表、好友列表、粉丝列表、主播在线/开播状态。
- 通知：
	- 系统消息、互动通知（被关注/被送礼）、关注主播开播提醒、平台公告。

### 工会（用户侧）

- **加入工会**：
	- 浏览/搜索工会，查看工会信息后提交入会申请，等待工会审批。
  - 工会列表：默认展示运营推荐的 5 个工会，其余工会隐藏，用户可通过关键词搜索查找后申请。
  - 加入限制：同一时间只能加入一个工会。
- **我的工会**：
	- 查看所属工会信息、成员/主播、公告。
  - 提交退出申请，需工会长同意后退出。
- **成为主播**：
	- 加入工会后申请开通直播权限，由管理后台开通后成为该工会主播；后台开启后，工会端亦可对名下主播的直播权限进行开启/关闭操作。

### 个人中心

- **资料与设置**：
	- 个人资料编辑、我的关注/粉丝、我的钱包入口、我的等级/勋章、我的主播认证入口。
  - 设置：账号、通知开关、隐私、语言切换（英语/马来西亚语/印尼语）、关于、账号注销、退出登录。
- **装扮**：
	- 查看我获得的头像框、气泡、勋章，可选择穿戴展示
  - 用户可同时佩戴多类身份标识（财富等级、消费等级、粉丝团等级勋章、守护等），粉丝团勋章与财富等级勋章分不同位置展示。
- 客服与帮助：在线客服/帮助中心/意见反馈入口。

### 合规与安全

- 内容举报：直播间/用户/消息举报入口，联动后台审核处置。
- 拉黑/屏蔽：拉黑用户、屏蔽消息。
- 封禁申诉：账号/主播被封禁后提交申诉，后台受理处理。
- 青少年/年龄保护：年龄分级提示、未成年防护提示。

## 用户/主播端 App —— 主播侧（加入工会并通过认证后解锁）

### 主播入驻与认证

- **主播认证**：
	- 申请成为主播：入口在个人中心，前置条件为已加入工会；提交真人/实名认证资料（证件照 + 基础信息），进入后台审核队列。
  - 认证状态流转：未认证 → 审核中 → 认证通过（解锁开播）/ 认证驳回（展示驳回原因，可重新提交）。
  - 认证审核由管理后台进行。
- **开通直播权限**：
	- 认证通过后，由管理后台开通直播权限（后台开启后工会端可开关）；权限状态在"成为主播"入口回显：申请中 / 已开通 / 已关闭（含原因）。

### 主播个人主页

- 主页展示：面向观众/粉丝展示主播头像、昵称、简介、粉丝数、主播等级（按累计收到的贡献值计算）、收礼/榜单标识、粉丝团入口。

### 开播设置与控制

- **开播设置**：
		- 开播准备：设置直播主题、封面和分类；开播前预览摄像头画面。
  - 房间类型选择：3 种——普通房 / 门票房（设门票金币价）/ 密码房（设密码，可选择是否在广场展示、从粉丝中授权可见名单）。门票房、密码房首版上架后经后台开关灰度开启，且不支持连麦或 PK。
  - 基础美颜：美颜与美型分别保存参数，每组单选当前调节项，强度为 0-100、默认 50；恢复默认会清除选中项并将全部参数重置为 50。参数只影响主播视频画面，不修改封面或历史直播记录。
- **开播控制**：
	- 开始/结束直播；开播触发向关注粉丝推送开播提醒。

### 直播间管理（主播侧）

- 互动管理：
		- 清屏、踢人、禁言/恢复发言、拉黑、设置/取消房管。
		- 屏蔽指定评论：点击公屏消息，再点击“屏蔽此评论”；主播和观众均不可见该条消息，其他消息不受影响。场次结束后保留处置记录。
- 现场数据：
	- 查看在线观众列表、本场贡献榜、本场收礼与实时收益。
- **在线用户识别与经营**：
	- 用户身份标识：在线用户列表与公屏为每个用户展示识别标识，① 新用户（首次进入本直播间）② 已关注/老粉 ③ 粉丝团成员（含该团等级、用户粉丝等级、亲密度/灯牌）④ 本场高贡献用户 ⑤ 历史高贡献用户 ⑥ 用户财富等级 ⑦ 关系状态（已禁言/已拉黑）。
  - 快速经营操作：主播点击用户唤起用户卡，可执行 关注/私信/@欢迎/送礼答谢、禁言/拉黑/设房管，便于针对性欢迎新人、维护老粉、感谢付费用户。
  - 进场分级提示：新用户、老粉、高贡献/高财富用户进场时，公屏区分展示（如"新朋友进入""老粉回归""贵宾进入"）。
- **房管协助：房管可协助执行踢人/禁言/屏蔽指定评论（操作作用域仅限当前直播场次，操作留痕）。**：
	- 主播可输入任意用户 ID 设置房管，无需在线或为好友；目标不得在该主播直播间黑名单内，且双方无账号拉黑关系。最多 3 人；授权对该主播后续所有直播持续有效，直至主播取消。

### 连麦与 PK

- **主播间连麦**：仅普通房支持。一期仅支持两位主播视频连线；由主播发起邀请、对方接受后建立连线；无观众上麦麦位，不支持超过两人的连线或 PK。连麦中双方画面分屏展示，可结束连麦。门票房、密码房不展示连麦或 PK 入口。

### 粉丝团管理（主播侧）

- 主播仅可创建一个粉丝团/粉丝群，粉丝群人数上限 500。
- **创建/设置粉丝团：名称、加入条件；查看粉丝团成员列表；粉丝团群聊。**：粉丝团等级：长时间不活跃将自动降级。
  - 粉丝团权益：仅做粉丝团等级勋章——按等级分档（如每 10/20 级换一档颜色/样式，高等级比低等级更豪华），在该主播直播间聊天展示。其余等级权益后续再扩。

### 主播收益与提现（主播侧）

- **收益**：
	- 实时收益展示：直播中按金币 1:1 展示收礼收益（前端不扣分成，分成后台/线下结算）。
  - 普通/定制礼物用户消耗与主播收益 1:1（App 内不体现分成比例，结算按商品 SKU 绑定的分成规则执行）；幸运礼物按用户消耗金币的 1%（暂定，后台可调）计入主播收益，与普通礼物收益合并展示、不单独设幸运礼物收益入口。
  - 小数处理：主播收益不足 1 的小数直接舍去（不四舍五入、不计算），满 1 才计入；收益与榜单均隐藏小数，保证展示干净、便于主播心算。
  - 收益账户与明细：累计收益、可提现余额、冻结中金额、收益流水。
- **提现**：
	- 一期主播提现以线下结算（工会/平台按月线下发放），主播端仅展示收益与提现记录；后台做提现记录与财务报表。

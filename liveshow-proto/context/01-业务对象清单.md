## 二、对象关系说明（核心关系）

| 对象A | 关系 | 对象B | 说明 |

## 三、属性归属说明（易误判为对象的项）

| 粉丝团等级 | 粉丝团 | 粉丝团自身的等级；长时间不活跃自动降级，不属于单个成员 |

| 亲密度 | 粉丝团成员关系 | 用户对该主播的一对一关系数值（如 1,023），不单独建模 |
| 违规次数 | 主播档案 / 用户账号 | 由违规处置记录聚合统计的派生字段 |
| 搜索历史、热门搜索词 | 用户账号 / 运营位配置 | 前者用户行为缓存，后者运营配置项 |
| 榜单排名数据 | —（派生数据） | 由赠礼记录按榜单配置聚合，实时/周期计算；发奖依据已确认落"榜单快照"对象 |
| 直播间封面、标题、分类标签 | 直播场次 | 每场开播设置 |
| 语言、通知开关、隐私设置 | 用户账号 | 个人设置项 |
| 灯牌样式、粉丝等级勋章档位 | 道具配置 / 粉丝团成员关系 | 样式由配置定义，用户粉丝等级决定对应档位 |
| 粉丝团等级勋章档位 | 道具配置 / 粉丝团 | 样式由配置定义，粉丝团等级决定对应档位 |

## 四、待确认问题

| 问题 | 背景 | 影响 |
|---|---|---|
| 资料审核承接 | App 有资料审核，后台尚无审核队列 | 需补后台队列或改为机审 |
| 工会结算与分账台账 | 两者是否同一数据的不同视图未明确 | 影响对账和状态归属 |
| 运营账号标记 | 标记归用户还是会籍、后台和工会谁优先未明确 | 影响开户和投放权限 |

## 五、校验结论

观看送礼、成为主播、提现结算和封禁申诉均有对象承接。提现结算仍依赖“工会结算与分账台账”的待确认结论；巡房排班和操作审计日志属于管理支撑对象。

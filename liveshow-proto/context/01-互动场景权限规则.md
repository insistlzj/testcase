# 互动场景权限规则

> 账号级关系先行，场景章节只定义该场景特有的权限和后果。

## 一、账号级规则

### 1.1 优先级

```
平台处置 > 账号拉黑 > 场景级限制 > 好友关系 > 默认禁止
```

### 1.2 账号关系

| 动作 | 作用域 | 统一后果 |
|---|---|---|
| 拉黑账号 | 账号 × 账号，双向生效 | 双方不能私信、不能发起或处理好友申请；已有好友关系保留但不可用 |
| 解除账号拉黑 | 原拉黑关系 | 恢复私信和好友申请资格；已有好友关系恢复可用 |
| 举报 | 账号 / 内容 | 生成平台举报工单，不改变互动关系 |
| 关注 / 取消关注 | 用户 → 主播 | 仅影响关注关系与开播提醒 |
| 好友申请 | 账号 × 账号 | 双方均未拉黑时可发起；通过后建立好友关系 |

账号拉黑不解除既有关注、好友或粉丝团关系，不改变亲密度、资产、历史消息或历史流水。

### 1.3 主播身份附加后果

拉黑双方中存在主播身份时，除账号级后果外，叠加该主播直播间的限制。

| 情形 | 直播间后果 |
|---|---|
| 主播拉黑用户 | 用户不可见、不可进入该主播的直播间 |
| 用户拉黑主播 | 用户不可见、不可进入该主播的直播间 |
| 双方均为主播 | 双方均不可见、不可进入对方的直播间 |

解除拉黑后，直播间可见与进入资格立即恢复；平台封禁和直播间黑名单不受影响。

## 二、直播间

### 2.1 主播 → 观众

| 动作 | 权限条件 | 即时后果 | 作用域与存续 |
|---|---|---|---|
| 禁言 | 直播中；目标在线 | 目标不能继续发公屏消息，不影响其已发消息 | 本场次，到期或主播解除后恢复 |
| 屏蔽指定评论 | 直播中；长按目标公屏消息并二次确认 | 该消息立即从本场公屏隐藏 | 本场次前台不可恢复；后台保留原文、操作人和时间 |
| 踢出 | 直播中 | 目标退出直播间；门票房门票立即失效 | 本场次不可重进，下一场恢复 |
| 加入直播间黑名单 | 直播中 | 目标不可进入该主播直播间 | 仅该主播直播间，直至主播解除 |
| 拉黑账号 | 已登录 | 按账号级规则处理 | 账号级；主播身份附加直播间限制，对方无法进入直播间 |
| 设置 / 取消房管 | 输入用户 ID；目标不在该主播直播间黑名单内，且双方无账号拉黑关系 | 授予 / 收回该主播直播间的协助处置权 | 无需在线或为好友；按主播长期有效，直至主播取消；上限 3 人 |
| 清屏 | 直播中 | 清空当前公屏消息 | 本场即时动作 |

### 2.2 观众 → 主播 / 观众

| 动作 | 权限条件 | 即时后果 |
|---|---|---|
| 拉黑账号 | 已登录 | 按账号级规则处理；目标为主播时不可见、不可进入其直播间 |
| 举报 | 已登录 | 生成直播间、主播或消息举报工单 |
| 申请好友 | 双方未拉黑 | 生成待处理好友申请 |
| 关注 / 取消关注 | 已登录 | 按账号级规则处理 |

## 三、粉丝群

团籍即群籍。账号拉黑不解除团籍；拉黑双方的群消息互相不可见，其他成员照常可见。

### 3.1 群主 → 成员

| 动作 | 权限条件 | 即时后果 |
|---|---|---|
| 发送群消息 | 已创建粉丝团 | 发送给成员；按账号拉黑关系过滤 |
| 移除粉丝团成员 | 目标为成员；二次确认 | 解除团籍和群籍；不影响关注；卸下身份标识；用户粉丝等级和亲密度前台清零，重入不恢复；不影响粉丝团自身等级 |
| 单人 / 全员禁言 | 已创建粉丝团 | 限制对应成员的群内发言；不影响私信和直播间公屏 |

### 3.2 成员 → 群 / 群主

| 动作 | 权限条件 | 即时后果 |
|---|---|---|
| 发送群消息 | 团籍有效；未被群禁言或平台发言封禁 | 消息送达群内；按账号拉黑关系过滤 |
| 主动退出粉丝团 | 成员身份有效 | 与被群主移出后果一致 |
| 拉黑账号 / 举报 / 申请好友 | 已登录 | 按账号级规则处理；举报生成工单 |

## 四、1 对 1 私信

私信只承载会话与消息；发送权限由账号级拉黑和好友关系共同决定。

| 动作 | 权限条件 | 后果 |
|---|---|---|
| 发送私信 | 双方未拉黑，且为好友 | 双向发送消息 |
| 回复直播间私信 | 对应场次仍在直播；双方未拉黑 | 回复后自动建立好友关系 |
| 删除好友 | 存在好友关系 | 解除好友关系，双方立即不能发送私信 |
| 删除会话 | 存在会话记录 | 仅从本端会话列表隐藏，不改变关系或服务端记录 |

## 五、账号拉黑与直播间黑名单

| 动作 | 作用域 | 影响 |
|---|---|---|
| 直播间黑名单 | 指定主播的直播间 | 仅限制进入该主播直播间 |
| 账号拉黑 | 账号 × 账号；存在主播身份时叠加直播间限制 | 私信、好友关系；主播直播间不可见且不可进入 |

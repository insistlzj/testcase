# 管理后台任务配置规则

> 适用范围：基础版本的用户任务配置。

## 1. 配置逻辑
任务由“动作、条件、奖励”三部分组成：
`用户完成动作 → 达成配置条件 → 用户获得奖励`
- **动作**：由系统定义，只能选择，不能新增；
- **条件**：由系统定义，和动作关联；
- **奖励**：从固定奖励类型和已上架的道具中选择；

任务类型：
- **单次任务**：任务只有一次。如：活动任务、首充奖励；
- **周期任务**：周期循环。如：每日任务、签到任务 。
- **成长任务**：任务一直存在，配置条件很多。

## 2. 动作/条件/奖励

| 用户动作 | 达成条件 |
| --- | --- |
| 登录 App | 连续天数1/2/3/4/5/6/7/... |
| 观看直播 | 累计观看时长（分钟）10/30/60/120/... |
|  |  |
| 赠送礼物 | 累计赠送次数 1/3/7/13/21/31/... |
| 赠送礼物 | 累计赠送金币 100/300/700/1300/2100/3100/... |
| 分享直播间 | 累计分享次数 1/3/7/13/21/31/... |
| 邀请拉新 | 累计有效邀请人数 1/3/7/13/21/31/... |

## 3. 奖励类型
奖励类型只有金币，且需手动领取。

# 过程记录还原

以下两份过程记录超过 GitHub 普通文件大小限制，远端以同名 `.gz` 文件完整保存。本地原 JSON 保留，不改变当前用例与基线。

- `context-transfer.json.gz`
- `context-transfer.before-context-update.json.gz`

在新的检出目录中，运行以下命令恢复原文件；`-k` 保留压缩文件，原文件已存在时不要覆盖：

```sh
gzip -dk work/liveshow-guild-admin-260915-001/context-transfer.json.gz
gzip -dk work/liveshow-guild-admin-260915-001/context-transfer.before-context-update.json.gz
```

压缩后已校验解压内容与本地原 JSON 的 SHA-256 一致。恢复后再运行依赖这些原路径的 MainBasis 追溯校验。

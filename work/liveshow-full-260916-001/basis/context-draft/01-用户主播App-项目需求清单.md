## 首页与福利 / 首页
来源：liveshow-proto/prototype/annotations/user.js；批注键：live-plaza.html
页面入口：liveshow-proto/prototype/pages/user/home/live-plaza.html；同页视图不新增独立模块。
### 场景描述
用户浏览直播列表，筛选内容并进入直播间。

### 字段
| 字段 | 规则 |
| --- | --- |
| 直播卡片 | 展示本场封面、主题、主播、分类和本场直播间访问次数。访问次数 = 本场成功进入直播间的访问事件总数；同一用户重复进入重复累计，列表曝光、密码校验失败、购票失败等未进入行为不计入。场次开始时从 0 累计，结束后固化。 |
| 房型 | 普通房无准入标识；门票房展示金币价格；密码房展示密码准入提示。 |
| 关注主播 | 仅展示当前用户已关注且正在直播的主播。 |
| Banner | 内容、排序、跳转和有效期由平台配置。 |
| 通知说明弹窗 | 标题“开启通知”；正文“开启后，你可以及时收到关注主播开播、互动消息及平台公告。”；按钮“暂不开启、开启通知”。 |
| 系统授权弹窗 | 模拟手机系统通知授权，按钮“不允许、允许”。 |

### 业务规则
1. 游客可查看主播榜、贡献榜和不同分类下的主播，并可进入福利页、邀请好友页。
2. 游客点击直播间、搜索、消息、我的或其他账号动作时不执行原操作，直接跳转登录页。
3. 热门排序权重、直播分类和运营 Banner 由后台配置。
4. 关注区仅展示已关注且正在直播的主播；无符合数据时隐藏。
5. 门票房购票后本场可重复进入；直播结束或被主播踢出后失效，购票写入消费明细。
6. “在广场展示”只控制密码房是否出现在首页热门区域，不参与准入校验；粉丝团成员限制按独立规则执行。
7. 密码房校验正确后进入；校验失败时保留当前页面并提示重试。
8. 登录成功后首次进入首页显示通知授权说明；选择开启或暂不开启后均不在后续登录中重复展示。

### 交互
1. 点击搜索 -> 进入搜索页。
2. 切换热门或新人、选择分类 -> 刷新当前直播列表。
3. 进房演示固定为：Ayu 显示拉黑或踢出拦截，Intan 显示门票拦截；每次点击 Lala 时，密码房拦截和非粉丝团成员拦截交替显示；其他直播卡片直接进入。
4. 通知说明点击开启通知 -> 模拟系统通知授权弹窗；点击暂不开启 -> 仅关闭说明，不请求系统权限。

## 首页与福利 / 主播榜
来源：liveshow-proto/prototype/annotations/user.js；批注键：host-ranking.html
页面入口：liveshow-proto/prototype/pages/user/home/host-ranking.html；同页视图不新增独立模块。
### 场景描述
用户查看平台主播收礼排名。

### 字段
| 字段 | 规则 |
| --- | --- |
| 周期 | 按平台业务时区计算：当日从当天 00:00 开始，本周从周一 00:00 开始，本月从每月 1 日 00:00 开始。 |
| 排名 | 依次按收礼值、主播等级、财富等级从高到低排序，仍相同时按主播 ID 数字部分从小到大排序；不设并列名次。 |
| 榜单数量 | 当日、本周、本月均最多显示前 30 名；第 30 名与第 31 名收礼值相同时，继续按排名规则确定顺序。 |
| 主播 | 展示头像、昵称、主播等级和当前开播状态。 |
| 收礼值 | 收礼值 = 周期内主播成功收到的非虚拟金币礼物单价 × 数量之和。幸运礼物按送出礼物价值计算，返奖不冲减收礼值；虚拟金币赠礼不计入主播榜。 |

### 业务规则
1. 主播等级或财富等级缺失时按 0 级参与排序；排名按完整排序结果连续编号。
2. 运营账号不进入任何榜单或排行；主播榜按收礼主播汇总，统计前过滤虚拟金币赠礼，不计入收礼值和排名。
3. 账号注销后保留历史数值，名称显示“账号已注销”，且不能进入主页。
4. 数据范围：所选当日、本周或本月的主播收礼汇总，按字段表中的排名规则最多展示前 30 名。

### 交互
1. 切换周期 -> 同步更新前三名、列表排名和收礼值。
2. 已登录用户点击主播 -> 进入该主播主页；游客点击 -> 直接跳转登录页。

### 场景描述
用户查看平台用户送礼贡献排名。

### 字段
| 字段 | 规则 |
| --- | --- |
| 周期 | 按平台业务时区计算：当日从当天 00:00 开始，本周从周一 00:00 开始，本月从每月 1 日 00:00 开始。 |
| 排名 | 依次按贡献值、财富等级从高到低排序，仍相同时按用户 ID 数字部分从小到大排序；不设并列名次。 |
| 榜单数量 | 当日、本周、本月均显示前 30 名；第 30 名与第 31 名贡献值相同时，继续按排名规则确定顺序。 |
| 统计对象 | 仅统计非运营账号；运营账号不进入任何榜单或排行。 |
| 用户 | 展示头像、昵称和财富等级。 |
| 贡献值 | 贡献值 = 周期内非运营账号成功送出的各礼物单价 × 数量之和。幸运礼物按送出礼物价值计算，返奖不冲减贡献值；运营账号及其虚拟金币赠礼不计入贡献榜。 |

1. 财富等级最低为 1 级；排名按完整排序结果连续编号。
2. 贡献榜按送礼用户汇总；运营账号不进入任何榜单或排行，统计前过滤运营账号及其贡献数据。
3. 账号注销后保留历史数值，名称显示“账号已注销”，且不能进入主页。
4. 数据范围：所选当日、本周或本月的用户送礼汇总，按字段表中的排名规则展示前 30 名。

### 交互
1. 切换周期 -> 同步更新前三名、列表排名和贡献值。
2. 已登录用户点击用户 -> 进入该用户主页；游客点击 -> 直接跳转登录页。

## 首页与福利 / 搜索
来源：liveshow-proto/prototype/annotations/user.js；批注键：search.html
页面入口：liveshow-proto/prototype/pages/user/home/search.html；同页视图不新增独立模块。
### 场景描述
用户按昵称、用户 ID 或房间号查找账号。

### 字段
| 字段 | 规则 |
| --- | --- |
| 搜索关键词 | 必填，去除首尾空格后不能为空；支持房间号、用户 ID 或用户昵称。 |
| 搜索历史 | 展示当前用户最近使用的搜索词，按最近使用倒序，去重后最多保留 10 条；不展示热门搜索词。 |

### 业务规则
1. 搜索历史仅保存在当前用户侧，不随账号跨设备同步。
2. 提交关键词后写入搜索历史；相同关键词移到首位，不重复新增；超过 10 条时删除最早一条。
3. 数据范围：仅当前用户的搜索历史；按最近使用时间倒序、去重后最多 10 条。

### 交互
1. 进入页面 -> 自动聚焦搜索框。
2. 关键词为空 -> 提示输入，不进入搜索结果页。
3. 提交关键词或点击历史词 -> 写入最近使用记录并进入搜索结果页。
4. 点击历史词右侧删除 -> 仅删除该条；点击清空全部 -> 删除全部搜索历史并显示空状态。

## 首页与福利 / 搜索结果
来源：liveshow-proto/prototype/annotations/user.js；批注键：search-results.html
页面入口：liveshow-proto/prototype/pages/user/home/search-results.html；同页视图不新增独立模块。
### 场景描述
用户查看当前关键词匹配的账号。

### 字段
| 字段 | 规则 |
| --- | --- |
| 搜索关键词 | 回填来源页关键词；去除首尾空格后不能为空。 |
| 用户头像、昵称 | 展示匹配账号的当前资料。 |
| 房间号 | 账号有主播身份时显示房间号，非主播不显示。 |

### 业务规则
1. 无匹配结果时保留搜索框并展示空状态。
2. 按账号搜索，每个匹配账号展示一条结果；有主播身份且正在直播时显示「直播中」标记，未开播主播及非主播账号均不显示。
3. 排序：精确匹配、前缀匹配、模糊匹配依次优先；同级按用户 ID 升序。

### 交互
1. 点击直播中的结果 -> 进入直播间。
2. 点击未开播账号 -> 有主播身份进入主播主页，非主播进入用户主页。
3. 修改关键词并提交 -> 刷新搜索结果。

## 首页与福利 / 充值福利
来源：liveshow-proto/prototype/annotations/user.js；批注键：welfare-center.html
页面入口：liveshow-proto/prototype/pages/user/home/welfare-center.html；同页视图不新增独立模块。
### 场景描述
用户进入邀请好友、充值福利，并在每日签到和任务中心手动领取金币奖励。

### 字段
| 字段 | 规则 |
| --- | --- |
| 邀请好友 | 展示当前活动配置的邀请奖励入口及奖励提示；点击进入邀请好友页。 |
| 充值福利 | 展示当前活动配置的充值赠送金币提示；点击进入充值页。 |
| 连续签到天数 | 展示当前账号连续手动签到成功的天数；仅登录不增加该数值。 |
| 签到进度 | 按连续签到周期展示已签到日、今日和后续签到日；每个日期同时展示对应金币奖励。 |
| 签到操作状态 | 今日未签到时显示「签到」；领取成功后显示「已签到」并禁用。 |
| 任务项 | 展示后台配置的任务名称、当前进度、目标值、金币奖励和领取状态。 |
| 任务操作状态 | 未完成显示去完成或不可领取提示；完成后显示领取；领取成功后显示已领取。 |

### 邀请好友
1. 点击卡片进入「邀请好友」P009。
2. 卡片「+10」数值取后台配置的每成功邀请 1 位好友可获得的金币奖励。

### 充值福利
1. 点击卡片进入充值页。
2. 卡片「+10金币」取套餐中赠送金币最多的数值。

### 配置来源
1. 每日签到与任务中心统一由管理后台「运营配置 → 任务配置」维护；配置四语名称、启停状态、生效时间、用户动作、统计维度、统计周期及条件对应的金币奖励。
2. 仅启用且处于生效时间内的任务产生新进度；停用不回收已领取奖励。奖励仅为金币，不自动发放。
3. 同一任务至少配置一个条件；条件为互不重复的正整数，每个条件对应正整数金币奖励。

### 每日签到
1. 对应后台「登录 App → 连续登录天数」，按「连续第 n 天」配置金币奖励；连续天数以手动签到成功为准，仅登录不计为签到。
2. 页面展示连续天数、已签到日、今天及后续奖励。当前原型演示已连续签到 3 天，今天领取 30 金币，第 7 天展示 +60；示例金额不代表固定业务配置。
3. 点击「签到」成功后才计入连续天数并领取当日金币；提示到账，按钮变为「已签到」并禁用，同一账号同一日不可重复领取。
4. 当日未手动签到即断签，即使已登录也拿不到当日奖励；次日登录后须重新手动签到，连续天数及奖励从第 1 天重算。
5. 超过后台配置的最高连续天数 n 后，第 n+1 天及以后每天签到均领取第 n 天的奖励，直至断签；不自动循环。
6. 例如仅配置第 1 天 +20、第 2 天 +30，则连续第 3 天起每天签到均领取 +30；断签后重新签到按第 1 天领取 +20。

### 任务中心
1. 任务使用后台预置动作及对应指标，如观看时长、赠礼次数或金币数、分享次数、有效邀请人数；展示名称、目标值、当前进度、金币奖励和领取状态。
2. 每日、每周、每月任务在新周期开始时进度归零；无周期任务在任务有效期内持续累计。可选周期以后台对应指标为准。
3. 达到条件后可手动领取该档金币；同一账号、同一任务周期内，每个条件独立领取一次。未达成不能领取，已领取不能重复领取。
4. 任务达标获得奖励后，须在获得奖励当天 23:59 之前手动领取；周期任务（每日、每周、每月）和无周期任务均适用，领取有效期不随任务周期延长。逾期奖励失效，不自动发放，也不能补领。领取时须校验有效期，已失效则不发放奖励并提示「奖励已失效」。

### 任务中心领取
1. 领取成功后更新领取记录、钱包金币余额及金币流水；重复点击或重试不得重复入账。领取失败时不改为已领取，提示失败并允许重试。
2. 当前 P012：观看任务未完成时点击奖励提示「任务尚未完成」；分享入口提示前往直播间分享；已达成的赠礼任务点击奖励后显示「已领取」。
3. 原型以 Toast 代替前往观看或分享的业务动作，仅模拟当前页领取状态；不实际发币、不持久化。
4. 游客可浏览并进入邀请好友页；签到、领奖和充值操作跳转登录。运营账号只可进入福利一级页，点击其中任意功能入口提示“运营账号无法操作”，不参与签到、任务及领奖。

### 边界
1. 不支持补签；跨日和任务周期按平台业务时区计算，每周从周一开始。
2. 任务停用前已获得的奖励，可在获得当天 23:59 前领取；逾期失效。

## 首页与福利 / 邀请好友
来源：liveshow-proto/prototype/annotations/user.js；批注键：invite-friends.html
页面入口：liveshow-proto/prototype/pages/user/home/invite-friends.html；同页视图不新增独立模块。
### 场景描述
用户邀请新用户，并查看邀请人数、奖励和邀请记录。

### 字段
| 字段 | 规则 |
| --- | --- |
| 已邀请好友 | 展示成功邀请的好友人数。 |
| 累计获得金币 | 展示邀请好友获得的金币合计。 |

### 交互
1. 切换奖励/邀请记录 -> 展示统计或记录列表。
2. 邀请记录超过一页 -> 点击上一页/下一页翻页。
3. 点击邀请好友 -> 打开复制链接、发送给好友和保存图片选项。
